# Frontend JavaScript

This directory contains JavaScript files for the frontend.

## Files

- `api.js` - Functions for interacting with the backend API
- `app.js` - Main application logic and initialization
- `chat.js` - Chat interface functionality

## Conventions

- No build step - files are served as-is.
- Use vanilla JavaScript (no frameworks).
- Keep functions small and focused.
- Avoid global variables; use modules or IIFE where appropriate.
