# Frontend Pages

This directory contains individual HTML files for different views of the application.

## Structure

Each HTML file represents a page or view:
- `index.html` - Main dashboard (located in parent frontend directory)
- `automations.html` - Email automation rule builder and completed-work history
- Other HTML files in this directory represent specific views (e.g., settings, profile, etc.)

## Usage

Pages are linked from the main `index.html` or via JavaScript navigation.

The shared dock navigation is injected by `frontend/js/dock.js` on sub-pages.
