# Frontend

This directory contains the frontend (client-side) code for the Mindbase AI application.

## Structure

- `index.html` - Main HTML file
- `assets/` - Static assets (images, icons, etc.)
- `css/` - Cascading Style Sheets
- `js/` - JavaScript files
- `pages/` - Individual HTML pages for different views

## Technologies

- Vanilla JavaScript (no frameworks)
- CSS with design tokens defined in `css/globals.css`
- No build step - served as static files

## Development

To develop the frontend, simply edit the HTML, CSS, and JavaScript files and refresh the browser.
