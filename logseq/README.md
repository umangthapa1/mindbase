# Logseq

This directory contains Logseq configuration and related files.

## Files

- `config.edn` - Logseq configuration file
- `custom.css` - Custom CSS for Logseq (currently empty)
- `.recycle` - Directory for deleted items (managed by Logseq)

## Note

This directory is used by the Logseq knowledge base application. Do not modify files unless you know what you are doing.
