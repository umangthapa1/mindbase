# .claude/settings.local.json

Local settings configuration for Claude Code.

## Purpose

This file contains local-specific settings for the Claude Code AI assistant, including:
- Permission configurations for local development
- Custom command shortcuts
- Environment-specific preferences
- Local MCP (Model Context Protocol) server configurations

## Contents

- Permission allowlists for local commands (Bash, MCP tools, etc.)
- Custom slash command definitions
- Local environment variable settings
- MCP server configurations for local development
- Editor and UI preferences specific to this machine

## Usage

This file is automatically loaded by Claude Code when working in this project directory. It works alongside the global settings.json file, with local settings taking precedence.

Note: This file should not be committed to version control as it contains machine-specific configurations.
