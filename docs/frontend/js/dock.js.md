# dock.js

Frontend dock component for application navigation and quick access.

## Purpose

This file implements the dock UI component that provides:
- Quick access to frequently used applications and features
- Application launching and switching
- Status indicators and notifications
- Dock item management (add, remove, rearrange)

## Contents

- Dock rendering and layout logic
- Drag-and-drop functionality for dock items
- Click handlers for launching applications
- Notification badge updates
- Dock item component definitions
- State management for dock visibility and position

## Usage

The dock is initialized in `app.js` and appears as a persistent UI element at the bottom of the screen. It integrates with the application launcher and task switching system.
