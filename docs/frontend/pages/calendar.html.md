# calendar.html

Calendar and scheduling page for the Mindbase AI application.

## Purpose

This page provides a calendar interface for managing tasks, events, and schedules, including:
- Viewing tasks and events in day, week, and month views
- Creating new tasks and events with natural language input
- Drag-and-drop rescheduling of tasks and events
- Setting reminders and notifications
- Viewing agenda and upcoming items
- Integrating with external calendars (if configured)

## Contents

- Calendar header with view selection (day, week, month)
- Calendar grid displaying days and time slots
- Task and event rendering with color-coding
- Modal forms for creating and editing tasks/events
- Drag-and-drop functionality for rescheduling
- Sidebar with agenda and upcoming items
- Reminder and notification settings

## Usage

Access this page from the main navigation. It uses the backend tasks service to retrieve and manage tasks and events, and supports natural language date/time parsing for quick input.
