# dashboard.html

Main dashboard page for the Mindbase AI application.

## Purpose

This page serves as the primary interface upon application load and provides an overview of:
- Recent tasks and upcoming deadlines
- Memory and knowledge base highlights
- Email summary and recent messages
- Calendar events for the day
- Quick access to common features and applications
- System status and notifications

## Contents

- Welcome message and user greeting
- Task summary panel (today's tasks, overdue, upcoming)
- Memory digest (recent memories, suggested memories)
- Email preview (unread count, recent emails)
- Calendar view for today
- Quick launch dock for frequently used applications
- Notification center and system status indicators
- Motivational quotes or daily insights (optional)

## Usage

This is the landing page of the application. It aggregates data from various backend services (tasks, memory, email, calendar) to provide a comprehensive overview of the user's productivity and information.
