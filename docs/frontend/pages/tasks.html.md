# tasks.html

Task management page for the Mindbase AI application.

## Purpose

This page provides an interface for managing tasks and to-do lists, including:
- Creating new tasks with natural language input
- Viewing tasks in various formats (list, board, calendar)
- Setting due dates, priorities, and reminders
- Organizing tasks with tags, categories, and projects
- Tracking task progress and completion
- Collaborating on tasks (if applicable)
- Integrating tasks with calendar and memory systems

## Contents

- Task input bar with natural language parsing
- Task list/view options (list, kanban board, calendar)
- Task cards with details (title, description, due date, priority)
- Drag-and-drop functionality for reordering and status changes
- Filters and search (by status, priority, tags, date)
- Task creation/edit form with detailed options
- Bulk actions (complete, delete, move, etc.)
- Task statistics and progress tracking

## Usage

Access this page from the main navigation or dashboard. It interacts with the backend tasks service to create, retrieve, update, and delete tasks. Supports natural language date/time parsing for quick task creation like "Finish report tomorrow at 2pm".
