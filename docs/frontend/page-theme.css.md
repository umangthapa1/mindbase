# page-theme.css

CSS file defining the theme and styling for individual pages in the frontend.

## Purpose

This file contains CSS styles that are applied to individual HTML pages in the frontend/pages/ directory, including:
- Page-specific layout and styling
- Component styling for page elements
- Responsive design adjustments
- Visual theme consistency across pages
- Overrides and extensions to the global CSS variables

## Contents

- Page layout containers and grids
- Header and footer styling for pages
- Card and panel components
- Form elements and inputs
- Button and link styling
- Table and list styling
- Modal and dialog styling
- Responsive breakpoints and media queries
- Dark/light theme adaptations (if applicable)
- Page-specific animations and transitions

## Usage

This CSS file is linked in each HTML page in the frontend/pages/ directory and works alongside the global CSS variables defined in frontend/css/globals.css. It provides page-specific styling while maintaining consistency with the overall application design system.
