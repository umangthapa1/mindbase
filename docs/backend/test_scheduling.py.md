# test_scheduling.py

Standalone test script for scheduling functionality.

## Purpose

This script provides manual tests for verifying the task scheduling and natural language date parsing functionality.

## Contents

- Tests for natural language date parsing
- Schedule creation and manipulation tests
- Reminder and notification scheduling tests
- Cron expression validation tests

## Usage

Run directly with Python:
```bash
python backend/test_scheduling.py
```

This script tests the functionality found in `tasks_service.py` and related modules.
