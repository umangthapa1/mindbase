# test_intelligence_context.py

Tests for intelligence context functionality.

## Purpose

This test file verifies the functionality of the intelligence module's context handling, including:
- Context extraction from user messages
- Context retention and retrieval
- Integration with memory and task systems
- Context-based response generation

## Test Cases

- Context extraction accuracy
- Context relevance scoring
- Context merging and deduplication
- Context expiration and cleanup
- Integration with conversational memory

## Usage

Run with pytest:
```bash
pytest backend/tests/test_intelligence_context.py
```
