# test.py

Standalone test script for backend functionality.

## Purpose

This script provides manual tests for verifying backend functionality outside of the automated test suite.

## Contents

- Manual test cases for core functionality
- Debugging utilities
- Verification scripts for specific features

## Usage

Run directly with Python:
```bash
python backend/test.py
```

Note: This is separate from the automated pytest test suite in `backend/tests/`.
